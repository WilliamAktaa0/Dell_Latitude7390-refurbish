# Refurbishing the Dell Latitude 7390 
## Initial System Specs: 
Tradition Clamshell with a 13.3-inch Full HD (1920 x 1080) anti-glare touchscreen, 8GB instlaled RAM, Intel Core i5-83500 CPU, 238GB M.2 NVME SSD, integrated 128MB Intel UHD Graphics 620.
## Upgrades:
Windows 10 Pro --> Windows 11 Pro

New Battery

8GB RAM --> 16GB RAM

## Battery Replacement:
The initial battery that came with this was severly degraded with a full charge capacity of only 15,139mWH / 60,002mWH, so I'm going to replace it with a new 60,002mWH battery.
